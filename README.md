# ODYSSEY — Techfest 3D Experience

A responsive, immersive Techfest landing page built with HTML, CSS, JavaScript and Three.js.

## Interactive features
- Real-time 3D crystal / portal rendered with Three.js.
- Drag the 3D object to rotate it.
- Pointer parallax, animated particle field, orbit rings and scroll-reactive motion.
- Four visual technology domains, mission section and CTA.
- Responsive mobile navigation and reduced-motion support.

## Run locally
Because the 3D scene uses JavaScript modules, run this folder through a local web server (for example, VS Code Live Server) rather than opening `index.html` directly. Internet access is required for the Three.js CDN and Google Fonts.

## Publish
Push the files to GitHub and enable GitHub Pages from `Settings → Pages → Deploy from a branch → main → /(root)`.

## Customize
Replace the fictional ODYSSEY / Techfest 2026 branding, event details, and placeholder contact address (`hello@odyssey.techfest.example`) with the official event information before submission.
